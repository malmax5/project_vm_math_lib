# MathLib

Библиотека математических функций для консольного калькулятора для системного программирования на Ubuntu Server 24.04.

## Особенности
- **Header-only**: не требует предварительной компиляции.
- **Без STL**: не использует стандартную библиотеку (namespace std).
- **Безопасность**: все функции возвращают признаки ошибок (переполнение, деление на ноль).
- **Namespace**: все функции обернуты в пространство имен `pvm_math_lib`.

## Реализованные операции
1. Сложение (`add`)
2. Вычитание (`sub`)
3. Умножение (`mul`)
4. Деление (`div`) — с проверкой на 0.
5. Возведение в степень (`pow`) — реализовано **итеративно**.
6. Факториал (`factorial`) — реализовано **рекурсивно**.
